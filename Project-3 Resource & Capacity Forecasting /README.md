# Project 3

## Financial Crime Operations: Strategic Resource Forecasting

Focus: Capacity Modelling · Scaling Strategy · Operational Resilience

### Project Summary

This project focuses on the Strategic Scaling of Socio-Technical Systems. Using an operational audit of a global financial crime team, I developed a Capacity and Resource Allocation Model to manage transaction volume surges of 25–50%. The project demonstrates how quantitative forecasting ensures that Human-in-the-Loop systems remain resilient, ethical, and sustainable during periods of rapid technological growth.

### Background & Context

In financial crime operations, sudden volume surges can create bottlenecks that force investigators to choose between speed and quality.

From a Sustainable Societies perspective, an overextended workforce represents a systemic risk. By quantifying operational capacity and automating low-value work, this project ensures that humans can focus on high-value reasoning, maintaining compliance integrity while protecting cognitive sustainability.


### Scope & Analysis

The analysis utilised operational datasets and performance metrics:

• **Baseline Audit:** 1,000 daily reviews managed by a 24-agent global team

• **Predictive Scaling:** Calculated headcount for a 25% volume increase with a 20% systemic buffer

• **Crisis Mitigation:** Prepared strategic response for a 50% surge



### Key Findings & Intervention

**1. Quantitative Resource Modeling**

Deterministic modelling showed that a 25% surge (1,250 reviews) requires expanding from 24 to 30 agents. This prevents compliance fatigue, a major driver of errors.

SQL Insight: Variance analysis from performance.sql revealed that resolution times increased by 18% during peak hours, validating the need for a systemic buffer.

**2. Intervention: Hybrid Intelligence & RPA Integration**

To mitigate extreme volume spikes without compromising safety, I proposed Hybrid Oversight:

• Deterministic Triage (RPA): Automating high-frequency, low-complexity verification tasks to reduce base-level cognitive load

• Strategic Reallocation: Redirecting human expertise to high-entropy cases (PEPs/Sanctions) requiring nuanced judgment

• Outcome: Stabilises Systemic Latency (Reach Speed) while protecting the workforce from the Normalisation of Deviance, which occurs under extreme productivity pressure



### Skill Set Demonstrated

• Operational Forecasting: Headcount modelling with systemic buffers

• Strategic Planning: Multi-tiered mitigation strategies combining human and automated resources

• Systems Resilience: Understanding how volume surges affect systemic latency and regulatory compliance

• SQL & Data Extraction: Identifying bottlenecks and correlating workload to resolution-time degradation



### Technical Implementation

As an individual, I:

• Performed gap analysis and calculated a 6-agent shortfall

• Conducted SQL-based performance auditing to identify bottlenecks and correlate volume spikes with resolution-time degradation (Average_Time_Minutes)  

• Defined success metrics emphasising Accuracy-at-Scale and Workload Equilibrium

• Designed Hybrid Oversight policies combining RPA and human expertise for sustainable operations
